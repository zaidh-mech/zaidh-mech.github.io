Oil Level Detection System

Developed a dedicated oil level monitoring system for the Brother S7300A sewing machine using an MS5837 pressure sensor and an ATmega328P microcontroller. Implemented fluid depth calculation with realtime display on an I2C 16×2 LCD and a threshold buzzer alert to prevent dry‑run damage. Calibrated for the specific tank geometry to enhance reliability and reduce maintenance risk.

Wearable Posture Detection Device

Proposed a magnetic field–based wearable posture detection system using neodymium magnets and magnetometer sensors. The system infers sitting posture changes and provides immediate haptic/audio feedback to encourage healthy ergonomics during prolonged desk work.
