Case 01

ToF Based SLAM & Autonomous Mobile Robot

An ESP32-based mobile robot built to localize itself, map an indoor environment and navigate using fused distance, inertial and wheel-motion data.

Context

Final year project

Timeline

Dec 2025—Present

Role

System design & build

Tools

ESP32, MATLAB, C++

Engineering narrative

Challenge

Create a compact autonomous platform that can estimate pose and map indoor space using cost-effective sensing and embedded control.

Architecture

ToF range measurements describe surrounding geometry while the IMU and wheel encoders estimate movement. The ESP32 manages acquisition, control and navigation; MATLAB supports mapping, visualization and performance analysis.

Key decisions

Separate sensing, pose estimation and motion-control subsystems so each can be validated independently before full integration. A custom 4-layer PCB consolidates sensor and actuator interfaces.

Validation

Compare estimated motion and generated maps against known paths and room geometry, then tune sensor fusion and control parameters from measured error.

Case 02

Automated Oil Level Monitoring System

An industrial monitoring system combining pressure-based level sensing, a custom control PCB and embedded alert logic for production machinery.

Context

Brother Industries

Timeline

Oct 2024—Apr 2025

Role

Electronics & firmware

Tools

ATmega328P, MS5837, C

Engineering narrative

Challenge

Replace manual oil-level checks with continuous monitoring that can identify an out-of-range condition reliably in an industrial environment.

Architecture

An MS5837 pressure sensor feeds an ATmega328P-based custom PCB. Embedded C processes the readings, applies thresholds and controls alert outputs.

Delivery

Electronic schematic, component selection, PCB layout, sensor integration, firmware and a practical testing sequence for dependable operation.

Validation

Calibrate level estimates against known oil levels, check threshold behavior and repeat trials to assess stability and false alerts.

Case 03

Automated Modified Iron

A garment pre-heating station integrating controlled heating, relay logic, timers, a pneumatic cylinder and movable arms for consistent production use.

Context

MAS Capital

Timeline

Jul—Dec 2025

Role

Automation engineer

Tools

CAD, controls, pneumatics

Engineering narrative

Challenge

Improve pre-heating consistency while reducing repetitive manual handling in a branded-apparel manufacturing process.

System

Relay and timer logic coordinate temperature control and pneumatic motion. Movable arms position the work consistently before pressing.

Mechanical design

CAD parts and assemblies translate reach, motion and installation constraints into a practical mechanism that production teams can operate and maintain.

Validation

Test cycle timing, heating consistency, cylinder motion and repeated operation; troubleshoot faults and optimize settings for production reliability.

Case 04

Wearable Active Posture Corrector

Research into a sensitive wearable posture-detection concept using neodymium magnets and Hall-effect sensors.

Context

OREL Corporation

Timeline

Jan—Apr 2024

Role

Research & prototyping

Domain

Wearable sensing

Engineering narrative

Question

Can compact magnetic sensing detect meaningful upper-body posture deviations with enough sensitivity for a wearable feedback device?

Approach

Investigate magnet and Hall-effect sensor placement, observe response to relative movement and develop a prototype-level wearable concept.

Evidence

Document sensing behavior, placement constraints and repeatability to identify what a future active feedback prototype must solve.
