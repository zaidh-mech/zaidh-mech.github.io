A focused selection from robotics, embedded systems, PCB design, CAD, and industrial automation work.

ToF Based SLAM and Autonomous Mobile Robot

Final year project developing a ToF-based autonomous localization and mapping system. The robot uses ESP32-based embedded control, IMU and wheel encoder fusion for pose estimation, real-time navigation and motion control, plus MATLAB tools for mapping, visualization, and performance analysis.

Automated Modified Iron

Industrial garment pre-heating system using relay logic, timers, temperature control, a pneumatic cylinder, and movable arms. Built to improve heating consistency, reduce repetitive manual effort, and support reliable production use.

03

Automated Oil Level Monitoring System

Industrial machinery monitoring system designed around an ATmega328P and MS5837 pressure sensor. The work included electronic schematic design, custom PCB layout, C firmware for data processing, alert logic, and reliability testing.

Wearable Active Posture Corrector Device

Research project investigating neodymium magnets and Hall effect sensors to detect upper-body posture deviations with high sensitivity, including sensing layout, wearable concept development, and prototype-level validation.
